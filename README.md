📌 Sobre o Projeto
Este repositório contém uma coleção de exercícios resolvidos e exemplos de código que abordam os conceitos básicos da linguagem C#. Ideal para iniciantes ou quem deseja revisar os fundamentos da linguagem.

🚀 Tópicos Abordados
Sintaxe básica do C#

Estruturas de controle (if/else, loops)

Manipulação de strings e arrays

Orientação a Objetos (Classes, Herança, Polimorfismo)

Tratamento de exceções

Coleções (Listas, Dicionários)

LINQ (Consultas em coleções)

E muito mais!
